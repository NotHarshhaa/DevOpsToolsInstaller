ENVIRONMENT HEALTH

Workstation Doctor & 5-Point Diagnostics

Catch silent configuration drift, broken paths, and binary collisions before they break scripts or CI builds. The Doctor asynchronously inspects:

  • PATH Conflicts & Duplicates: Redundant segments, malformed syntax, non-existent directories.
  • Missing Prerequisites: Hyper-V virtualization, WSL2 kernel readiness.
  • Multi-Version CLI Collisions: Detects competing binaries (e.g., terraform in both Tools\bin and Chocolatey\bin).
  • Outdated Catalog Tools: Compares active CLI versions against the cryptographically signed catalog.
  • Unregistered Tools\bin: Verifies standalone CLI binaries are registered on User PATH without admin rights.

Every "Fix" requires explicit user confirmation before applying, and exports markdown reports for IT tickets.

NETWORK RESILIENCE

Resumable Transfers & Context-Aware Actions

Large vendor packages (Docker Desktop ~550 MB) shouldn't restart from zero because Wi-Fi dropped. Every transfer writes to a companion .partial file and resumes automatically via HTTP Range requests.

Files are promoted to target filenames only after SHA-256 checks pass. The app then triggers context-aware deployment:

  • Installers (.msi, .exe): Launches official vendor wizard with native UAC elevation.
  • Archives (.zip): Cleanly extracts into sandboxed user folders and symlinks/copies to Tools\bin.
  • Binaries (.exe): Places standalone CLIs directly into user Tools\bin.
  • Scripts (.ps1): Opens folder for manual inspection — scripts are never auto-executed.
HTTP RANGE RESUME .PARTIAL FILES CONTEXT DEPLOYMENT ZERO SILENT RUNS

FILE LOCATION CONTRACT

Storage Paths (%LOCALAPPDATA%)
%LOCALAPPDATA%\DevOpsToolsInstaller\ ├── Downloads\ (Active and verified vendor artifacts) ├── Tools\<tool-id>\ (Sandboxed extracted tool folders) ├── Tools\bin\ (Portable CLIs added to User PATH) └── logs\ (Daily timestamped activity audit files)

Never touches machine-wide directories (Program Files, System32) or machine environment variables (HKLM) without explicit vendor installer elevation.

WORKSTATION POWER TOOLS

CLI Health Probing & Shell Completions

The Installed view isn't just an inventory list. It actively probes each installed CLI binary (using --version or -v) and measures process latency in milliseconds to verify execution health.
