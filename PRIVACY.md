# Privacy Policy for DevOps Tools Installer

**Last updated:** September 20, 2026

DevOps Tools Installer ("we", "our", or "the application") is committed to protecting your privacy. This Privacy Policy explains our data practices.

### 1. Information Collection and Use
DevOps Tools Installer is a standalone, local Windows desktop utility. 
* **No Personal Data Collection:** The application does not collect, track, store, or transmit any personally identifiable information (PII).
* **No Telemetry or Analytics:** The application does not send telemetry, tracking cookies, or analytics data to any third-party servers.

### 2. Network Operations
The application connects to the internet strictly for the following functional purposes:
* Fetching updated tool catalog definitions from the official GitHub repository.
* Invoking package managers (such as Windows Package Manager `winget` or Chocolatey `choco`) to download and install developer tools directly from their respective official publisher sources as requested by the user.

### 3. Local Data Storage
Any configuration settings or cached catalog information are stored locally on your device within your user profile directory and can be removed at any time by uninstalling the application or deleting the application data directory.

### 4. Third-Party Services and Tools
When you choose to install third-party developer software through this installer, the installation and use of those specific tools are governed by the respective publishers' terms and privacy policies.
